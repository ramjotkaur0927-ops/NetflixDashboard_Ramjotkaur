# Netflix Content Analysis Dashboard

This Tableau dashboard provides an in-depth analysis of Netflix content across multiple dimensions.

## Key Insights:
•⁠  ⁠Distribution of Movies vs TV Shows
•⁠  ⁠Ratings breakdown across content
•⁠  ⁠Top genres on Netflix
•⁠  ⁠Country-wise content availability
•⁠  ⁠Year-wise growth of content

## Tools Used:
•⁠  ⁠Tableau
•⁠  ⁠Data Visualization
•⁠  ⁠Data Cleaning

## Features:
•⁠  ⁠Interactive filters (Title, Type)
•⁠  ⁠Dynamic charts and maps
•⁠  ⁠Genre and rating analysis

## Objective:
To analyze Netflix content trends and provide insights into user preferences and global distribution.
